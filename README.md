# ⚔️ Bushi (2D Pixel Action Game)

> **Unity 6**로 개발한 픽셀 아트 스타일의 2D 모바일 액션 게임입니다.  
> 하늘에서 쏟아지는 장애물을 **칼로 베어내며** 살아남는 무사(Bushi)의 이야기로, 콤보와 **피버 타임** 시스템을 통한 짜릿한 손맛을 제공합니다.

---

## 🛠️ 개발 환경 및 사용 기술 (Tech Stack)

* **Engine:** Unity 6.3 LTS (6000.3.25f1)
* **Language:** C#
* **Render Pipeline:** 2D Universal Render Pipeline (URP)
* **UI System:** TextMeshPro (Galmuri 도트 폰트, RASTER 렌더링)
* **Input:** Input System (키보드 + 멀티 터치)
* **Platform:** Android (가로 화면 고정, Safe Area 대응)
* **Assets:** Custom Pixel Art Sprites & SFX/BGM

---

## ✨ 핵심 기능 (Features)

* 🏃 **플레이어 컨트롤 & 애니메이션**
  * `← / →` 방향키로 수평 이동, `Spacebar`로 점프, `Q`로 공격, `1 / 2 / 3`으로 스킬 (개발 테스트용 키보드 조작)
  * 모바일 화면 버튼 지원 (좌우 이동 / 점프 / 공격 / 스킬), 손가락을 떼지 않고 좌우 버튼 사이를 미끄러뜨려도 방향 전환
  * Animator 기반 IDLE / RUN / JUMP / ATTACK / SKILL / DIE 상태 전환 (v1.1: 25프레임 새 캐릭터 애니메이션)
  * 칸 단위 슬라이스 + 발밑 Custom Pivot으로 프레임 간 위치 흔들림 제거, 공중 프레임은 장마다 발 높이에 맞춘 피벗
* ⚔️ **공격 & 쿨타임 시스템**
  * 바라보는 방향 전방 + 머리 위를 커버하는 공격 판정 범위 (일정 시간 동안 연속 판정)
  * 공격 성공 시 짧은 쿨타임(0.5초), 실패 시 긴 쿨타임(3초) 적용
  * 플레이어 머리 위 쿨타임 게이지 및 모바일 공격 버튼 쿨타임 표시
* 🪵 **장애물 시스템**
  * 통나무·바위 등 4종 장애물이 화면 상단의 랜덤한 위치에서 수직 낙하
  * 낙하 시 랜덤 기울기 적용, 시간이 지날수록 생성 간격 단축 (최대 0.5초 간격)
* 🔥 **콤보 & 피버 타임**
  * 장애물 연속 파괴 시 콤보 증가, 콤보가 높을수록 파괴 점수 증가
  * 5콤보 달성 시 피버 타임 발동: 쿨타임 제거, 파괴 점수 2배, 무적 상태
  * 피버 시작 시 장애물이 대량으로 쏟아지는 보너스 연출, 종료 시 화면 정리 후 1초간 생성 중지
* 🌀 **스킬 시스템 (v1.1)**
  * **Cyclone Slash** — 제자리 회전 베기, 머리 중심 정사각형 범위의 장애물 파괴 + 발밑 흙먼지 이펙트
  * **Triple Combo** — 3연속 베기와 함께 관통하는 검기 3발 발사 (화면 밖까지 비행)
  * **Rising Crescent** — 공중에서 점프를 한 번 더 누르면 재도약하며 거대한 초승달 검기 발사, 맞은 장애물은 파편 3배
  * 스킬별 쿨타임, 원형 쿨타임 덮개와 남은 초가 표시되는 스킬 버튼, 스킬별 효과음
* 🪙 **코인 & 스킬 상점 (v1.1)**
  * 피버 타임에 장애물을 파괴하면 `Coin +1` 문구와 함께 회전하는 코인이 튀어나오는 연출 + 코인 효과음
  * 코인은 `PlayerPrefs`에 영구 저장, 메인 메뉴·인게임 점수판 옆에 보유 코인 표시, 게임 오버 화면에 이번 판 획득 코인 표시
  * 메인 메뉴 SHOP에서 코인으로 스킬 구매 (구매한 스킬만 버튼이 나타나고 사용 가능)
* 💥 **시각 & 타격감 연출 (Juice & VFX)**
  * 장애물 파괴 시 코드로 생성되는 조각(Debris) 효과
  * 파괴 / 피버 시작 / 게임 오버 상황별 세기가 다른 카메라 흔들림(Shake)
  * 파괴 지점에 떠오르는 점수 팝업 (피버 중 색상 변경)
* 🎵 **오디오 시스템 (SFX & BGM)**
  * 씬 전환 시에도 유지되는 싱글톤 AudioManager, 2곡의 BGM 교대 재생
  * BGM / 버튼 클릭음(SFX) / 공격·파괴음(EFFECT) 3채널 볼륨 조절 및 `PlayerPrefs` 저장
  * 게임 오버·피버 시작 효과음 랜덤 재생
* 📱 **모바일 대응**
  * 다양한 화면 비율(16:9 ~ 21:9)에 맞춘 배경 자동 크기 조절
  * 노치·펀치홀을 피하는 Safe Area UI 배치
  * 일시정지 기능 (`Esc` 키, 앱 전환 시 자동 일시정지)
* 📈 **점수 및 게임 관리**
  * 생존 시간 점수 + 장애물 파괴 보너스 점수
  * `PlayerPrefs` 기반 최고 점수(Best Score) 영구 저장 및 메인 메뉴 표시
  * 게임 오버 화면 (점수 / 최고 점수 / 획득 코인 / NEW BEST 표시, 다시 하기 / 메인 메뉴)
